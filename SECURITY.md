# Security Policy

## Supported versions

Only the latest release on the default branch receives security fixes.

## Reporting a vulnerability

If you discover a security issue, **do not** open a public GitHub issue.

Describe the issue privately (minimal reproduction, impact, and version) via GitHub **Security advisories** on this repository, or contact the repository maintainer directly if advisories are unavailable.

## Deployment warning

This project is a **local development proxy**. Running it on the public internet without authentication, HTTPS, and rate limiting can expose your network and Mullvad exit to abuse. Do not deploy as an open proxy.
